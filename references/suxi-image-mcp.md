# Suxi gpt-image-2-vip MCP

Use this reference only when the user needs thesis figures generated by Suxi `gpt-image-2-vip`. If the user does not need image generation, skip this step completely.

## User Setup

Tell the user:

1. Register a Suxi account if they do not already have one.
2. Top up at `https://new.suxi.ai/console/topup`.
3. The expected billing model from the user's workflow is `1 CNY = 1 USD credit`; each generation consumes `0.12 USD credit`, approximately `0.12 CNY`.
4. Create an API key at `https://new.suxi.ai/console/token`.
5. Send the API key in the current session only if they want image generation configured.

## Secret Handling

- Never write the API key into `SKILL.md`, examples, references, or committed files.
- Inject the key only into the active agent's local MCP configuration as `SUXI_API_KEY`.
- Redact the key in all logs and replies.
- If the user says they do not need image generation, do not ask for the key.

## Bundled MCP Server

Path:

```text
mcp/suxi-image/suxi_image_mcp.py
```

The server is a minimal stdio MCP implementation with no third-party Python dependency. It exposes:

- `suxi_check_config`: checks API key presence and exact endpoint metadata without revealing the key.
- `suxi_create_gpt_image_2_vip`: calls `POST https://new.suxi.ai/v1/images/generations`.
- `suxi_upload_image`: calls `POST https://new.suxi.ai/api/upload`.

## Exact API Contract

### Create gpt-image-2-vip

```http
POST https://new.suxi.ai/v1/images/generations
Authorization: Bearer <SUXI_API_KEY>
Content-Type: application/json
```

Request body:

```json
{
  "model": "gpt-image-2-vip",
  "prompt": "论文插图提示词",
  "size": "3840x2160",
  "quality": "low"
}
```

### Upload Image

```http
POST https://new.suxi.ai/api/upload
Authorization: Bearer <SUXI_API_KEY>
Content-Type: multipart/form-data
```

Form field:

```text
file=<binary image file>
```

## Thesis Figure Workflow

Before calling the image tool:

1. Draft figure title, purpose, placement, elements, and caption.
2. Prefer Mermaid/draw.io for architecture, flow, sequence, and database diagrams.
3. Use `gpt-image-2-vip` mainly for bitmap-style academic illustrations, conceptual figures, cover-like visuals, or polished explanatory graphics.
4. Save outputs under `images/` or `images/generated/`.
5. Report absolute output paths so the user can inspect them.
